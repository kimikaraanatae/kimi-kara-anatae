## この企画の立場

このメディアは中立ではありません。象徴天皇制の発展的解消を提案します。

一方で、検証手続は公正であることを目指します。事実と解釈と提案を分け、強い反対論を弱く加工せず、未解決事項と結論の修正条件を公開します。皇族個人の意思を推測・代弁せず、個人を制度論や運動の道具として扱いません。
