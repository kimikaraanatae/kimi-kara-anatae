# 記事本文スナップショット

noteで公開した時点の本文Markdownを、記事ID・版ごとに保存します。

```text
articles/
  A001/
    v1.0.md
    metadata.json
```

公開前の記事本文はnote下書きを正とし、GitHubには置きません。公開後はnoteを読者向け最新版とし、このディレクトリには版保存、訂正、復旧のための公開時点スナップショットを収録します。

## 分類の管理

- 読者向けの棚：noteマガジン
- 記事の主分類、版、公開状態、関連研究、訂正：`ARTICLE_INDEX.md`
- 公開時点の詳細メタデータ：各記事スナップショットのYAMLと`metadata.json`
